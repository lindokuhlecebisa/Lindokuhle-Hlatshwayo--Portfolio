# Industrial Cybersecurity Monitoring System

##  Overview
A Python-based simulation of an industrial cybersecurity monitoring system designed for environments such as mining operations. The system generates real-time activity logs, detects anomalies, and triggers security alerts.

---

##  Features
- Real-time log generation
- User activity simulation
- Rule-based anomaly detection:
  - Multiple failed login attempts
  - Admin login failures
  - Suspicious IP detection
- Alert system for security events

---

##  Tech Stack
- Python
- File Handling
- Rule-based logic
